# 10 — Definition of Done

## Mỗi phase

- Code hoàn thành đúng scope.
- Unit test PASS.
- API/integration test PASS.
- Browser test phù hợp PASS.
- Console/network sạch.
- Không hardcode hoặc fake data.
- Docs cập nhật.
- Security impact đã review.
- Working tree sạch sau commit.
- Handoff cập nhật.
- Acceptance exit code `0`.

## Dự án cuối

- 8 service canonical hoạt động.
- Data giữ sau restart.
- Auth/session/role matrix PASS.
- SSRF PASS.
- Password Checker không gửi password.
- CVE/Asset/Watchlist/SOC/Digest/Crawler hoạt động.
- Export an toàn.
- Rasa validate PASS.
- Playwright PASS.
- Không secret trong Git.
- Responsive PASS.
- Submission tag được tạo.

Không dùng từ “hoàn hảo”, “ổn định tuyệt đối” hoặc “100%” nếu không có bằng chứng đầy đủ.
